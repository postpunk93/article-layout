# Соглашение по оформлению черновика (Google Docs)

Источник истины для конвейера — то, как размечен документ в Google Docs. Парсер
(`src/parser.py`) опирается на эти правила; адаптеры площадок переносят результат
максимально близко к оригиналу. Оформляй черновик строго по соглашению, тогда
заголовки и блоки переносятся одинаково на все площадки.

## Заголовки

| Стиль в Google Docs | Роль                  | Куда попадает                                   |
|---------------------|-----------------------|-------------------------------------------------|
| Heading 1           | Название статьи        | Поле заголовка площадки (ровно один на документ) |
| Heading 2           | Подзаголовок 1-го уровня | VC «Подзаголовок H2» / Pikabu «Заголовок 1»     |
| Heading 3           | Подзаголовок 2-го уровня | VC «Подзаголовок H3» / Pikabu «Заголовок 2»     |

- **Ровно один Heading 1** — это название. Второй и последующие H1 игнорируются
  (в заголовок не попадают и блоком не становятся).
- Площадки поддерживают **только два уровня подзаголовков** (H2 и H3). Заголовки
  глубже (H4 и ниже) парсер **не собирает вообще** — их текст потеряется. Не
  используй H4+.
- Не имитируй подзаголовок жирным абзацем — используй стиль Heading 2/3, иначе он
  приедет как обычный текст.

## Цитаты

- **Жёлтая заливка текста** (highlight `#ffff00`) = блок-цитата. Выделяй жёлтым
  весь абзац цитаты целиком.

## Картинки и подписи

- Картинка вставляется как изображение Google Docs (не ссылкой).
- **Курсивный текст сразу под картинкой** = подпись к ней. На площадках с нативным
  полем подписи (например, Pikabu) подпись уезжает в это поле.

## Списки

- Маркированные и нумерованные списки Google Docs переносятся как списки.
- Поддерживаются **плоские** списки (без вложенности). Вложенные списки и пункты,
  обёрнутые в дополнительные блоки, не гарантированы.

## Замечание про импортированные черновики

Документы, **скопированные с другой площадки** (например, вставка статьи с Хабра),
часто несут чужую разметку — характерный случай — статья целиком на Heading 3 без
структуры H1/H2. Такой черновик нужно **переоформить в Google Docs** по этому
соглашению перед прогоном. Если такой документ всё же прогнать как есть, контент
H2/H3 не теряется (например, одинокий H3 без H2 всё равно станет подзаголовком
2-го уровня), но визуальная иерархия будет верной только при правильной разметке
источника. Заголовки H4+ — исключение: они выпадают целиком (см. выше).
